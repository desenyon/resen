# Resen 0.2.1

The first downloadable Resen release: a terminal-native financial research desk
with model connections, source-led memos, local archives and historical studies.

## Install

macOS and Linux, on Intel/AMD x86_64 or ARM64:

```sh
curl -fsSL https://github.com/desenyon/resen/releases/download/v0.2.1/install.sh \
  | sh -s -- --version v0.2.1
~/.local/bin/resen --demo
```

No compiler or sudo required. The installer checks the archive's SHA-256,
version and command help before atomically replacing the executable. Run it
again to reinstall or upgrade without changing your research or credentials.
Use `--dir DIRECTORY` to choose another location.

Windows x86_64: download `resen-windows-x86_64.zip`, extract it and run
`.\resen.exe --demo`. Every archive contains the binary, documentation, license
and release metadata. `SHA256SUMS` covers the five archives and installer.

## What's improved

- Downloadable native macOS and Windows binaries; static Linux binaries for
  both architectures, exercised on Alpine and Debian by the release pipeline.
- Compact terminals keep setup, research submission, strategy controls and
  running-job cancellation visible.
- Scrollable help, useful empty views, clearer source origins, price context,
  archive summaries and study metrics.
- Better Unicode input, visible cursors, pasted searches and recoverable form
  errors. Twenty-one new UI regression tests cover these repairs.
- Installer failure-path tests preserve the previous executable after failed
  downloads, bad checksums, wrong versions and invalid archives. Native release
  gates run Rust checks and actual Unix terminal/process lifecycle suites.

## Requirements and scope

macOS builds target 13 or newer; macOS binaries are unsigned and not notarized.
Linux binaries use musl and do not require a matching glibc. Use a truecolor
terminal; 80×24 supports the compact layout and 60×18 is the minimum.

`--demo` runs completely offline with explicitly synthetic fixtures. Live
research needs your model/service credentials and data entitlements. Real
QuantConnect/LEAN account execution and all vendor endpoints have not been
accepted against user accounts. Resen does not execute model-generated strategy
code automatically or place orders. Saved credentials are private plaintext
files rather than an OS keychain.

See the README for models, data sources, keyboard controls and source limitations.
